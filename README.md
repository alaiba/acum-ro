# acum.ro

Explorăm o **rețea socială pentru România**, construită pentru **impact de lungă durată și sustenabilitate financiară**.

**Stadiu: explorare.** Domeniul este acum.ro. Forma produsului, comunitățile de început și modelul de finanțare se stabilesc prin discuție.

## Începem aici

- [Prima discuție: sustenabilitate financiară și impact durabil](https://github.com/alaiba/acum-ro/discussions/1)
- [Document de pornire: modele, riscuri și o simulare financiară](docs/sustenabilitate.md)
- [Toate discuțiile](https://github.com/alaiba/acum-ro/discussions)

**Întrebarea de pornire:** ce valoare creează acum.ro pentru oameni și cine ar plăti recurent pentru ca această valoare să continue să existe?

## Cum contribuim

Folosim **Discussions** pentru idei, întrebări și obiecții, iar **Issues** pentru acțiunile concrete stabilite ulterior. Discuțiile sunt în română; exemplele și argumentele concrete sunt binevenite.

Ipotezele și propunerile sunt marcate ca atare. Deciziile se consemnează după discuție.
